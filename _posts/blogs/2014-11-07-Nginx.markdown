Nginx (pronounced engine-x) is an open source reverse proxy server for HTTP, HTTPS, SMTP, POP3, and IMAP protocols, as well as a load balancer, HTTP cache, and a web server (origin server). The nginx project started with a strong focus on high concurrency, high performance and low memory usage. It is licensed under the 2-clause BSD-like license and it runs on Linux, BSD variants, Mac OS X, Solaris, AIX, HP-UX, as well as on other *nix flavors. It also has a proof of concept port for Microsoft Windows.

## Run on Mac OS X:
Install with Homebrew

{% highlight bash %}
$ brew install nginx

$ sudo nginx 

## Note: you may need to grab the ownership of the folder.
$ sudo chown {yourName} /usr/local 

{% endhighlight %}


Then, test via:
http://localhost:8080

Note: The default place of nginx.conf on Mac after installing with brew is:
/usr/local/etc/nginx/nginx.conf


The nginx default port is 8080, we shall change it to 80. First stop the nginx server if it is running by:

{% highlight bash %}
$ sudo nginx -s stop

$ vim /usr/local/etc/nginx/nginx.conf

server {
    listen       8080; -> 80
    server_name  localhost;

    #access_log  logs/host.access.log  main;

    location / {
        root   html;
        index  index.html index.htm;
    }

{% endhighlight %}

Save configuration and start nginx by:  

{% highlight bash %}
$ sudo nginx
{% endhighlight %}


Update local instance:

{% highlight bash %}
$ sudo nginx -s stop


$ vim /usr/local/etc/nginx/nginx.conf
