Kev's Tech Blog
=========================
## Get Started ([HELP](https://help.github.com/articles/using-jekyll-with-pages/))

```txt
---
#First, check:
ruby --version
#Then
gem install bundler + bundle exec jekyll serve
#or
gem install github-pages + jekyll serve
---
```

## How to update
 - Place a image in `/img/portoflio/`
 - Create posts to display your projects. Use the follow as an example:
```txt
---
layout: blog
category: blogs
title: 'Welcome to NYMag Dev Blog'
date: '2014-11-19'
author: Kgao
tags: 'Github,Marketdown'
---
```
