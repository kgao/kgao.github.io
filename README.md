Kev's Tech Blog
=========================
## How to update
 - Place a image in `/img/portoflio/`
 - Create posts to display your projects. Use the follow as an example:
```txt
---
layout: blog
category: blogs
title: 'Welcome to NYMag Dev Blog'
date: '2014-11-19'
author: Kgao
tags: 'Github,Marketdown'
---
```
